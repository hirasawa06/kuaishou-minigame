# AI 生图素材规范

本规范用于快手小游戏 AI 生图时的图片尺寸、分辨率、色彩模式和文件格式要求。

## 尺寸要求

根据素材用途选择合适的图片尺寸：

| 素材类型 | 建议尺寸上限 |
|---|---|
| 小图标、道具、按钮图标 | 128×128 或 256×256 |
| 普通角色、怪物、建筑 | 不超过 512×512 |
| 大型角色立绘、局部特写 | 不超过 1024×1024 |
| 全屏背景 | 按目标游戏分辨率制作；竖屏通常为 1080×1920，横屏通常为 1920×1080 |
| 长背景、地图 | 切片处理，不直接提交一张超长 4K/8K 图片 |
| 单张纹理 | 不超过 2048×2048 |

如果素材需要适配多个用途，按其中要求最高的目标尺寸生成；不要为了通用而默认生成超大图片。

## 文件要求

- 分辨率：建议 72 PPI。
- 色彩模式：RGB。
- 文件格式：优先使用 PNG 或 JPG。
- 需要透明背景时使用 PNG；不需要透明背景且更关注文件体积时可使用 JPG。
- 导入游戏前检查图片实际像素尺寸、色彩模式和文件格式，不要只依据文件名或生成参数判断。

## 生成流程要求

1. 先确认素材用途、目标画面方向（竖屏或横屏）和目标游戏分辨率。
2. 按用途选择合适的尺寸，不得直接使用超过需求的 4K/8K 图片作为普通素材。
3. 长背景或地图拆分成多个切片后再导入。
4. 生成后检查像素尺寸、RGB 色彩模式和文件格式。
5. 将处理后的素材放入游戏项目约定的资源目录，并遵守项目自身的资源命名和目录规范。

## 本项目角色参考规则（强制）

本仓库生成角色、怪物、角色动作或角色三视图时，除遵守上述尺寸与格式外，必须同时满足以下输入约束：

1. **情绪版为必带风格参考**：每次 AI 生图都必须读取并随生成请求提供 `tower-defense/tools/src/characters/情绪版/` 中相关图，锁定本项目的 3D 卡通材质、灯光、圆润比例与战斗可读性；不能只用文字描述模仿风格。
2. **三视图为必带结构参考**：生成或修订某角色的正 / 侧 / 后三视图时，必须随请求提供该角色目录中的 `*三视图参考*.png`。它负责锁定轮廓、部件位置、朝向与脚底基线；情绪版只负责风格，不能替代三视图。
3. **动作图双参考**：生成待机、移动、攻击、受击或死亡动作时，必须同时参考情绪版和已确认的该角色三视图；武器、装饰、攻击外扩可变，但身体比例、关键部件与脚底基线不可漂移。
4. **参考缺失即暂停生成**：没有情绪版，或三视图任务没有对应三视图参考图时，不得直接出正式素材；先向用户索取或建立并确认该参考图。

每次资产记录都要注明参考图路径与角色源目录。既有素材若早于本规则产生，保留现状；后续重做时必须补齐上述参考链。

本规范是推荐的 AI 生图尺寸与格式基线；如果平台审核规则、项目技术方案或具体素材用途有更严格要求，以更严格要求为准。
