# 冰箱 Boss 砸地特效

状态：已实现，H5 定格及合同检查通过；动态观感和快手真机待验。2026-11-17。

## 用户决定

- 使用用户2026-11-17提供的三阶段透明PNG：小范围冰裂、紫烟与食物扩散、残光。
- 在现有范围攻击0.48秒命中帧启动；只替换旧圆环与六枚冰屑，不改变伤害、攻击范围或攻击间隔。
- 冲击贴地绘制于角色下方，冰裂圆心固定在冰箱待机双脚地面点；击杀特效独立保留。

## 实现

- 归一化源帧表：`tower-defense/tools/src/vfx/冰箱Boss/冰箱Boss砸地-用户确认-v6.png`。原图4344×1214，已有透明通道，不做去白底。
- 三幅构图共用缩放和冰裂圆心，不逐帧裁边填格；256px格内保留透明边距，输出768×256运行时PNG。
- 离线生成器：`tower-defense/tools/gen-boss-impact.py`；来源哈希与取图圆心见源素材目录的`砸地特效来源.json`。
- 运行时配置：`Config.BOSS_IMPACT`。画布宽260逻辑像素，透明留白不等于有效冲击直径；原图透视保持，不旋转或横向拉伸。
- 三阶段起点0/0.10/0.30秒，总时长0.70秒；末帧从0.30秒开始渐隐至完全透明。
- 2026-11-17 21:03：按用户反馈，特效相对脚底落点向下偏移画布宽的8%（260px画布下为20.8逻辑像素）。实战与动作场共用偏移，Boss本体、脚底阴影与伤害中心不变。
- 正常混合保留紫烟、蓝色冰裂与食物配色，不套角色光影滤镜；动作场与实战共用资源、取帧和命中时刻。

## 验证

- `boss-impact-check.mjs`：三阶段取帧、共享圆心、末帧渐隐、角色下层只绘制一次。
- `sim.mjs`：砸地命中前不结算；命中后只生成一次特效；动作场同一命中时刻启动，切动作清除残留；400秒上限玩法模拟通过。
- 资源门禁、阴影、治疗、刀光及光影状态回归通过；透明边缘为零，H5三个阶段定格已生成并检查爆发帧。
- H5目视不代表快手真机验收；不因本次特效接入声明完成平台发布。
- 包体预检失败：主包19.34 MiB超过6 MiB门限（已有体积问题仍在），另有8条模板/配置/资源路径警告。
