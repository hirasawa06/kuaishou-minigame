# 角色动作素材接入与尺寸验收规范

状态：本轮整理的操作规范（2026-11-16），随 `1112-deng` 审阅，未合入 main。新增数值门槛为建议验收基线，自动门禁待实现，不代表存量角色已经达标。

适用：英雄、怪物动作的新增与替换。配合[角色行动动画制作规范](角色行动动画制作规范.md)使用。

## 1. 核心规则

**身体决定比例，脚底决定位置，完整内容决定画布。三者分别测量。**

- 同一角色同一朝向以确认的待机帧为基准，禁止各帧裁到可见外框后分别填满图集格。
- 头部、躯干等稳定结构参与体型标定；武器、耳饰、尾巴、翅膀、光晕、拖尾不参与主体测量。
- 美术修正不改变 `radius`、碰撞、伤害、射程和治疗时机；不能通过放大全角色或改占地修补单帧。
- 跳跃、蹲伏、倒地允许自然改变投影高度，不能强制拉成同一外框。

## 2. 开始前建立基准卡

在角色源目录记录以下信息。原稿保留，派生图另命名；无法可靠测量的项目标为待标定，不从透明外框猜测。

| 必填项 | 记录内容 |
|---|---|
| 来源 | 原始附件、文件路径、像素尺寸、透明通道、版本日期、适用授权范围 |
| 基准 | 已确认的待机帧；正背朝向分别标定并记录体型关系 |
| 稳定结构 | 至少两个参考结构或参考点，例如头部宽度与躯干宽度，标明测量线 |
| 脚底 | 双脚接地中心或约定落点的原图像素坐标；尾巴末端不是脚底 |
| 目标 | 414 宽基准下的主体尺寸、绘制参考尺寸和逻辑占地，分别记录 |
| 例外 | 姿态、透视或变身的合理尺寸变化，以及用于核对的替代结构 |

## 3. 标准操作步骤

### 第一步：审图与取帧

1. 检查真实像素和透明通道，在深、浅底分别检查毛发、光晕、残点和截边。
2. 拼图逐格审查。光晕或武器跨格时不能等宽硬切；扩大取图范围并排除邻帧，无法分离则优先使用独立透明帧。
3. 原图不覆盖，另存派生图，记录裁切矩形、缩图及去残边步骤。留白补偿应在过早缩成小图前标定。

### 第二步：匹配主体比例

1. 将新动作与同朝向基准并排，对照头、躯干等稳定结构。
2. 在相同目标坐标系计算：`归一化倍率 = 基准结构长度 ÷ 新动作结构长度`；至少再用一个结构交叉核对。
3. 只做等比缩放。若头与躯干需要明显不同的倍率，先判定素材比例是否错误；不能横向拉伸凑大小。
4. 蹲伏、跳跃或倒地用仍可比较的身体结构核对，不匹配整图总高度。透视例外需记录依据。

### 第三步：对齐落点

- 缩放后将脚底锚点对齐同一角色参考坐标，不按每张图的透明外框重新居中。
- 坐标关系：`目标位置 = 目标脚底 + 归一化倍率 ×（原图位置 − 原图脚底）`。
- 跳跃保留地面投影锚点，身体离地写入动作时间线；有意攻击位移与素材错位分别记录。
- 分别核对正背、左右持械，不能用镜像掩盖持械手或结构变化。

### 第四步：分离光效与主体

- 新制素材默认角色动作与光效分层。杖头、枪口记录局部锚点，脚下光环记录地面锚点。
- 标明作用对象、角色上/下层、时长及淡入淡出，不依赖调用顺序猜测。
- 用户提供的合成帧无法无损拆开时可保留，但体型测量仍排除光效并记录例外。
- 低透明像素可能是光晕，不能统一当噪点删除；裁切阈值和渐隐区域必须可追溯。

### 第五步：打包与接入

- 先确定主体目标大小，再给武器、光晕安排画布。当前 128px 格（有效区 120px）放不下时使用大格或独立纹理，并同时接入 H5 与快手；不得把主体挤小。
- 需要透明边缘的素材，完整内容外四周至少留 4 个纹理像素安全区，最外边 alpha 为 0；缩图和图集量化后重新检查。只给已截断的图加透明边框不算修复。
- 裁边可以优化存储，但必须保留裁切偏移、主体比例和锚点，以恢复相同角色坐标。
- 帧级静态补偿随图标切换，不插值到其他动作；呼吸、后坐、跳跃等有意变化才进入动作时间线。
- 源图映射、帧变换、出手时刻放在 `tools/src/animation-specs/<id>.json`；修改后重建图集及运行数据，不手改生成文件。
- 临时 `frameTransforms` 必须记录测量依据、倍率、偏移和叠图证据。仅凭目测写入一个系数，不视为正式等体型验收。

## 4. 验收标准与交付物

以下为新增工作建议采用的门槛，按 414 宽逻辑坐标衡量，尚未实现自动检测。

| 项目 | 通过标准 | 失败处理 |
|---|---|---|
| 主体比例 | 同朝向、近似透视下，稳定结构长度差不超过 3% | 重做比例标定；透视例外单列依据 |
| 落点 | 无刻意位移时，切帧脚底误差不超过 1 个逻辑像素 | 修正锚点/裁切偏移，不改战斗坐标 |
| 叠图 | 待机与动作以同一脚底、50% 透明度叠放，稳定结构无突然胀缩 | 返回素材或坐标标定 |
| 光效 | 最终纹理在深浅底均无直线截边、串色或邻帧残边 | 恢复内容或扩大画布，不以裁光代替 |
| 连播 | 手机实际大小下，正常速度和慢放均无非设计性的变小、跳位 | 检查图标补偿、插值和回待机 |
| UI | 攻击/治疗期间 HUD 和卡池连续显示，无绘制异常，混合/裁切状态恢复 | 复现并补回归，不能吞异常掩盖 |

每次交付附：基准标注图、并排图、半透明叠图、最终纹理的深浅底检查图、实际大小动作预览、测量和测试结论。纹理目视、H5 实播、快手真机分开记录，不互相替代。

## 6. 奶猫案例与存量处理

本轮问题依次为：跨格光晕被截断、淡光被透明阈值裁掉、完整画布挤小主体、手工补偿缺乏主体测量。当前治疗图标仍使用 `scale=1.4` 和纵向偏移，这是现状，不是正式等体型验收结论。下次重制或验收时补齐基准与叠图，再决定是否保留补偿；既有角色不因本规范自动批量返工。
