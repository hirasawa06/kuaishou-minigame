# 弹窗多机型适配决定

状态：决定/已实现，快手真机待验证。时间：2026-11-21。

用户反馈SE上弹窗占屏过大，要求统一适配所有弹窗。以430逻辑宽度下340宽的既有弹窗为基准，设置、体力、头像选择、邀请、暂停、胜负结算统一按安全宽度340/430布局；新宠展示保持安全宽度55%。高度不足时统一等比收紧，面板保持在可交互区内。

面板、文字、图标、圆角与按钮同步等比变化，点击几何由同一变换派生。全屏遮罩独立使用画布坐标。绘制阶段保留设计坐标，结束或异常后恢复布局与绘制状态。

验证：375×667、430×932、320×568、390×844布局及变换专项通过；Chrome SE/Pro Max设置、体力、头像、邀请、暂停、胜利、失败、新宠展示截图与设置模拟触摸通过。浏览器音频播放中断与此次尺寸改动无关，关闭音频后独立验证弹窗。尚无快手真机验收结果。

## 15:08 最新决定

SE仍占屏过大，统一加入参考可用区430×836的高度约束，缩放取宽度与高度能容纳的比例。375×667比前版再缩小约22%，430×932保持原尺寸；其他较短屏按可用高度进一步收紧。布局及Chrome双尺寸展示和设置模拟触摸检查通过，真机待验。
