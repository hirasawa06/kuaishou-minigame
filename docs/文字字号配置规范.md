# 文字字号配置规范

状态：2026-11-18 21:15用户决定，1118-deng已实现七档字号；运行画面与真机待验证。

## 决定

所有游戏文字使用最终逻辑像素字号描述，不在文字调用中传入单独的缩放比例。固定为12、14、16、20、24、32、40七档；最小12、最大40。设备截图像素受DPR影响，不能直接当作逻辑字号。

| 字号 | 用途 |
| --- | --- |
| 12 | 版本、倒计时与次要状态 |
| 14 | 设置选项说明、辅助文字 |
| 16 | 正文、属性与体力数值 |
| 20 | 选项、关卡名称、导航和分享按钮 |
| 24 | 关卡数字、主要弹窗按钮 |
| 32 | 设置与弹窗标题 |
| 40 | 开始游戏、强调主标题 |

参考：Google官方[Material Design 3 Typography](https://developer.android.com/develop/ui/compose/designsystems/material3#typography)，查阅日期2026-11-18。官方按display/headline/title/body/label分层，包含12/14/16正文、24/28/32标题等档位，并明确产品可减少默认层级。本项目采用其角色分层方法，根据用户指定12—40极值与卡通游戏场景自行定义上述七档；并非直接照搬Android sp值，40为本项目自定上限。

旧字号请求就近归档，同距取较小档；如18→16、28→24、48→40。关键首页和弹窗按上表显式配置。容器变化、按压和长文本都不能生成额外字号。

## 现状

- `draw.text(text,x,y,fontSize,color,align)`：只接受最终字号。
- `draw.textWidth(text,fontSize)`：使用同一最终字号测量。
- `draw.centeredText(text,cx,cy,fontSize,color)`：按最终字号的可见字形居中。
- `draw.fitTextSize(text,fontSize,maxWidth)`：只能选择不高于请求档位的七档字号，最低12。
- `draw.fittedText(...)`：先按档位适配；12档仍放不下时使用省略号，不越过容器。容器连省略号都放不下时不绘制文字。核心固定标签仍按布局保留完整显示。
- 设置/收藏/体力弹窗、开始按钮、首页体力栏、卡牌、结算及教程文字均迁移到上述接口。卡牌名称与属性共享最终字号，保留既有宽度约束。容器按压动画与图片尺寸处理不属于文字字号接口。
- 字体素材仍复用现有18/28/48图集；素材选择、纹理像素与逻辑字号换算由绘制底层处理，调用者不指定图集字号及倍率。没有新增字体文件。

## 验证

`tools/font-size-check.mjs`验证七档实际绘制几何、12—40边界、宽度测量、可见居中与0/3/8/24/48/100宽度长文省略；菜单交互、布局与语法检查通过。字号限制在绘制层统一执行，所有游戏文字均受约束。不同图集的字形提示存在细微差异，需运行画面目视；快手真机待验。未提交或推送。

## 场景字号使用表（2026-11-18 21:22决定）

以下为后续设计与开发的指定基准字号，适用于当前页面以及新增同类组件。基准不是截图的像素高度。七档限制已实现；场景角色尚未全部逐项对齐，差异见末节。本次补充规范文档不代表这些差异已完成代码修改。

### 首页

| 元素/场景 | 基准字号 | 使用规则 |
| --- | ---: | --- |
| 开始游戏 | 40 | 首页最高层级，正常/按压状态字号相同 |
| 关卡圆章数字 | 24 | 按数字可见边界对齐内圆圆心，多位数字不另加档位 |
| 关卡名称 | 20 | 与圆章数字区分层级，长名称先调整名称区宽度 |
| 设置、收藏等导航标签 | 20 | 同级导航使用相同字号 |
| 体力当前值/上限 | 16 | 例如30/30；数值变化不改变字号 |
| 恢复倒计时、已满等次要状态 | 12 | 同一栏统一12，不随体力条比例产生其他字号 |
| 首页轻提示 | 14 | 例如头像已保存；不得成为比关卡名称更强的层级 |
| 禁用开始按钮文案 | 24 | 例如尚未解锁；与40的主行动区分 |

## 选档与适配规则

1. 新增组件先按上表选角色和字号；不得按“看起来差不多”新增档位。新场景使用已有角色，确需新增角色时先补充本表。
2. 容器移动、大小变化、按钮按压与动画不改变基准字号。窄屏先压缩装饰留白、调整容器和换行；内容仍放不下才逐档降级。
3. 核心标题与主要按钮最多降一级：40→32、32→24、24→20；普通正文16→14；辅助文字14→12。12不能继续降低。同级重复组件应一起降级，不能一张卡16、另一张卡12。
4. 固定操作文案、关键资源数值、关卡数字必须完整显示；不能用省略号或隐藏代替适配。昵称、可变列表名称允许省略，详情必须能看到完整内容。说明正文优先换行。
5. 文字水平/垂直居中以可见字形边界为准，不以字号的一半或字形图片边框代替。容器尺寸与字形尺寸分别计算。
6. 多行正文建议行高为字号的1.5倍；单行标题/按钮按字形居中，预留上下空间。此为后续排版要求，目前位图字形lineH与手工行距尚未全面统一，不能宣称已实现统一行高。
7. 程序可使用最终字号适配接口，但实际绘制只能落在七档内。直接写18/28/48等旧请求会就近归档，仅作为迁移兼容；新代码必须写规范档位。
8. 设计标注注明逻辑字号、角色、对齐、换行/省略规则及窄屏降级方案。手机截图/导出图上的物理像素不作为另一套字号标准。
