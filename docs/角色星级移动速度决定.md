# 角色星级移动速度（决定）

2026-11-19 21:07（最新决定/现状）：奶糖喵档案「回血」更名为「治疗量」，删除「治疗间隔」属性行；实际治疗量和治疗周期保持原值，档案随行数收紧，消耗饼干仍固定末行。

2026-11-19 21:04（修复/现状）：「速度」标签消失是三档字形图集均缺少速、度字，数值未丢失。重建字形图集补齐，更新预览缓存版本；新增属性文案后必须同步生成图集并检查用字覆盖。

2026-11-19 21:03（最新决定/现状）：收藏档案字段名称使用「速度」，所有数值仅展示数字，不带单位。治疗间隔仍沿用原毫秒数值换算，仅移除单位文案；速度仍为52/65/78。消耗饼干固定末行。

2026-11-19 20:54（决定/现状）：后续新增角色数值须同步登记统一收藏属性目录，收藏档案自动读取1/2/3星实时值；消耗饼干无论目录位置均固定在最底行。移动速度已加入，驻守角色三档为0时隐藏。攻击间隔继续隐藏，治疗间隔继续显示。

2026-11-19 20:45，用户要求会主动位移的角色拥有移动速度，星级越高速度越高。

当前主动位移角色为锤锤喵；1/2/3星分别为52/65/78逻辑像素每秒，沿用1星原速度，高星倍率为1.25/1.5。追击和回位共用此速度，攻击过程仍不主动移动。其余驻守角色各星级移动速度保持0；拖拽部署与碰撞退让不属于主动移动速度。

移动速度与攻击速度分别配置，通过统一星级属性派生函数用于购买、合成及预览。实际视觉和真机效果待验证。
