# 普通柜怪与 60°镜头设计

状态：**已确认**（2026-11-08）

## 已确认

- 后续新制或重制的角色、怪物、飞弹与特效，统一使用相机位于战场正南、朝正北、俯角 60°的镜头。
- 已验收的 70°素材与台灯小怪既有的 45°素材保留，不因规则调整返工。
- 普通怪采用现代圆角双抽屉柜：可见主体宽度 55–60（414 宽基准），逻辑直径 40。
- 柜体为浅原木与暖白抽屉面；两枚黄光眼睛独立置于上抽屉上方的凹槽中。眼睛不是抽屉拉手；抽屉保留普通、独立的把手。

## 已确认的结构母版

- 已确认无背景、正面 / 左侧 / 背面并列的 60°三视图；三面保持同一柜体高度、抽屉位置、四脚落点与脚底基线。
- 母版归档为 `tower-defense/tools/src/characters/角色/普通柜怪/普通柜怪三视图参考-v1.png`。之后的待机、移动、攻击、受击与倒地动作必须同时使用该母版和情绪版风格图。

## 已确认的首轮行动方案

- 动作源采用一张透明 2×2 动作表 `普通柜怪动作-v1.png`，按“待机、迈步、攻击蓄力、攻击命中”顺序排列；不在本轮制作受击或倒地姿势。
- 待机：四只短脚稳站、柜体竖直，黄眼轻亮。
- 移动：四脚交替迈步，柜体轻微前倾后回正；不跳跃，避免与台灯小怪的跳步语义重复。
- 攻击蓄力：柜体整体下沉并稍向后压，抽屉保持闭合。
- 攻击命中：柜体以黄眼所在的上沿为先整体前探撞击；命中时刻固定在攻击开始后的 0.24 秒。抽屉不伸出、不张开，黄眼保持独立黄光眼睛，不变为拉手或嘴部。

## 接入边界与验证

- 现有战斗图集为 1024×1024、64 格且已用满。新增四帧时扩为 1024×1152、72 格；不改单格 128px、4px padding 或旧帧顺序。
- 新增 `normal.json` 动画规格、普通柜怪 Rig 与图集帧；普通怪逻辑直径从 30 调为 40（`normal.radius: 15 → 20`）。攻击力、生命、攻速、移速、金币、波次和基地伤害不变。
- 图集生成后依次运行资源门禁、400 秒仿真、布局检查、普通柜怪待机 / 移动 / 蓄力 / 命中定格、浏览器战斗回归和包体预检；快手真机另行验证。

## 不在本次范围

- 不制作普通柜怪的受击、倒地、独立特效或其他朝向帧；受击与倒地维持现有通用回退，直到另行制作并验收。
- 不重制任何已验收英雄、台灯小怪或哈利边牧特效。
