更新：2026-11-03。记录基点是本仓库当前路径：仓库根目录负责协作与策划，`tower-defense/` 负责唯一游戏工程。后续把有用的策划约束纳入这里。

## 当前路径与真源

| 路径 | 作用 | 变更条件 |
|---|---|---|
| `tower-defense/package/` | 当前小游戏实际代码与资源 | 单独工程分支实现、测试后合并 |

## 已确认的表现规则

### 盾狗背面受击与晕倒（2026-11-05，当前分支待合并）

- 来源：本次用户确认的盾狗表现；状态：已在工作区实现。
- 决定：盾狗不攻击；战场待机与受击均使用背视。嘲讽维持原有的敌人目标选择规则，但不播放光盾；受击必须有可见后移下沉与回正。
- 决定：盾狗受击维持背视；被击败时向后仰面倒地，头朝战场南侧。倒地姿势全程不渐隐，随后使用所有角色共用的三帧纯白烟雾直接移除。
- 实现：源图放 `tools/src/characters/角色/盾狗/`，`tank.json` 驱动图集和 Rig；正面柴犬分件不再进入战场，仅供卡牌头像使用；光盾源图与运行时渲染已移除。

### 角色行动动画制作规范（2026-11-05，当前分支待合并）

- 来源：本次用户确认的后续制作流程；状态：已写入《角色行动动画制作规范》。
- 决定：未来新增角色可只提供角色图与角色特点；实现方按职业特点自动判断行动样式、方向帧、命中时刻、分件或整体姿势帧方案与通用特效复用方式。
- 决定：角色动作源按角色目录归档，死亡烟雾等可复用效果独立归档在 `tools/src/effects/`；攻击伤害与投射物起点必须来自 Rig 数据，不能为角色另写硬编码时间点。
- 实现：英雄和敌人统一经过 `idle / move / atk / hurt / die` 生命周期；死亡完成后播放通用烟雾。动作规格 JSON 是图集与 Rig 的单一来源，图集自动排格并在冲突或容量耗尽时失败。

### 射手猫背面单发攻击（2026-11-04，当前分支待合并）

- 来源：本次用户确认的实现请求；状态：已在 `petsAndFurniture-art-assets` 工作区实现，尚未合入 `main`。
- 决定：本次先将射手猫的战场表现固定为背面动作；攻击节奏为蓄力 0.10 秒、独立开火姿势 0.12–0.18 秒并发射一枚光弹、0.46 秒回到待机。目标在左右两侧时分别使用对应动作，但枪始终由角色右手持有。伤害只在该光弹到达目标时结算。
- 决定：射手猫被击败时向身后倒下，使用用户提供的“仰面倒地”姿势：脸在战场南侧、身体与尾巴朝北侧，保留螺旋眼和星环。姿势全程保持不透明，落地后播放三帧纯白烟雾并直接移除单位。
- 实现：角色原始参考与动作源统一归档在 `tools/src/characters/角色/<角色名>/`，不再将多个角色素材平铺在 `角色/` 根目录；跨角色风格参考归档在 `tools/src/characters/情绪版/`，全角色共用的死亡烟雾归档在 `tools/src/effects/defeat-smoke/`。
- 工程影响：角色动作采用离线图集帧，枪口和单发光弹由 WebGL 加法混合绘制；原始角色参考素材迁出 `package/res/`，不参与游戏包体。
- 待验证：快手 iOS / Android 真机的纹理内存、帧率与视觉可读性；正面动作尚未制作。

## 只迁入有用的限定

| 类型 | 迁入内容 | 如何使用 |
|---|---|---|
| 产品目标 | 游戏方向为《猫狗大战家具》；快手用户；操作爽感优先，收集猫狗服务于新的操作体验 | 写入策划总览，待团队确认具体玩法实现 |
| 体验结构 | 家中总览承担关卡衔接，单局战斗独立设计；正式产品期望连续游玩 30–60 分钟 | 用于规划关卡与中断恢复，不作为现有 Demo 单局时长承诺 |
| 世界观 | 异变家具与猫狗守护生活物品；家具功能与动机应关联关卡 | 作为关卡和角色设计依据，细节仍是提案 |
| 平台约束 | 独立 JS Runtime、WebGL 1.0 自绘、单机、本地资源、安全区动态适配、平台 API 经封装层 | 与本仓库 Skill 及真机结果核对后落实；适配层只读冲突单独处理 |
| 协作方式 | 策划、工程、测试各自记录证据；`main` 保持可运行，短期分支审阅后合并 | 作为跨会话和跨设备的工作约定 |

## 不迁入的内容

- 旧白盒的具体数值、路线、牌序和实现方式；如需参考，先与当前 Demo 对照并单独决策。
