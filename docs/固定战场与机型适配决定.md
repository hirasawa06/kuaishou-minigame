# 固定战场与机型适配决定

状态：决定／当前分支已实现，快手真机待验证。

来源：用户指出短屏怪物到家路线明显短于长屏，并授权采用更合适的适配方案。

## 决定

固定逻辑战场396×500，以414×896现有设计坐标为基准。出怪Y=106，家停止线Y=594；同一怪物初始条件、速度、射程、碰撞及可部署范围均独立于设备尺寸。随机出怪偏移仍保留，比较机型时需使用相同随机条件。

战场按可用宽高取较小缩放比例，水平居中、底部接操作台；长屏和宽屏额外区域只展示背景。短屏会缩小角色与守卫物，操作台和HUD独立保持宽度适配。背景没有强行拉伸角色、修改怪物速度或增加可部署空间。

新增battle-world.js统一转换，战斗更新在固定坐标中运行，绘制、光照、裁切、部署落点与角色命中转换到对应坐标。旋转或尺寸变化保留实体的逻辑位置。

## 验证

2026-11-21 15:28｜MyFlicker（决定/现状）：战场使用固定396×500逻辑地图，出怪点到家488逻辑像素；屏幕仅等比缩放，长屏余量不参与战斗。操作台仍按安全宽度独立适配；同步部署、角色命中、拖卖、教学亮区、裁切和光照坐标。四尺寸几何、三尺寸真实怪物485帧首次伤家、部署避让及真实输入拖卖通过；近战/目标选择、菜单、弹窗、预览回归与平台预检通过（5项既有警告）。已做桌面浏览器实战绘制目视，真机与完整难度待验；未提交。

测试：tower-defense/tools/fixed-world-check.mjs。真实无阻挡台灯从固定出怪点到首次伤家均为485帧（60Hz），包含起手时间；路线长度不代表任意随机出生位置的完全相同耗时。
