# 攻击距离与追击边界

状态：2026-11-19 20:22 已实现，自动回归通过；H5实际动画与真机待验证。

录屏中战士到达攻击边界后停止攻击；复现发现中心距离77.24000000000001而攻击距离77.24，追击停止与严格距离比较形成死区。原26组位置中7组卡死。

统一规则：

- attackReach只从攻击范围与目标半径计算中心距离；不修改脚底碰撞半径。
- 追击目标为攻击范围内1px，避免停在精确边界。
- attackInRange供选目标及命中共用，计算容差0.5px。
- 已有目标额外保持1px边缘余量，防止微小位移反复走停；超出即停止命中并重新追击。
- 保留已有目标，死亡或超出保持范围后再按原优先级选目标。

参数集中于config.js，角色数值母版不变。范围容差和保持余量仅用于边界稳定，可能使贴近边缘的既有攻击多命中一次；不允许远距离攻击。

回归工具：tower-defense/tools/attack-distance-check.mjs。覆盖234组基地边缘/星级/体型，额外墙边与不同更新步长，以及获取范围、已有目标、离开范围和死亡目标。
