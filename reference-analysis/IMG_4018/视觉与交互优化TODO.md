## P1｜核心操作与局内反馈

- [ ] **I01 按钮按压、松开与禁用反馈**：统一首页开始、暂停/继续、刷新、扩建和弹窗确认的短促压下、回弹、成功反馈；只缩放透明按钮本体，不带出背景切片边缘。参考：[02 主界面入口 00:07–00:17](clips/02_home.mp4)、[05 奖励确认 00:52–01:06](clips/05_tasks_rewards.mp4)、[08 选择面板 01:41–01:54](clips/08_choice_return.mp4)。**验收**：点击即见反馈；视觉边界与安全区内命中区一致；连续点击不堆积动画。
- [ ] **I02 卡牌拖起与跟手**：卡牌开始拖动时抬升、出现接触阴影，跟手时展示清楚的角色预览；头像点详情仍与卡牌拖动区分。参考：[06 主玩法首段操作 01:06–01:34](clips/06_board_core_intro.mp4)、[09 连续操作 01:54–02:35](clips/09_board_core_loop.mp4)。**验收**：触点不被预览遮挡；快速拖动不断帧；没有背景矩形边缘。
- [ ] **I03 合法落点与失败回退**：合法部署区与角色落点有双重提示；越界、饼干不足、席位已满各有简短反馈，取消拖动后卡牌恢复原位。参考：[06 棋盘操作反馈 01:06–01:34](clips/06_board_core_intro.mp4)、[14 返回主玩法 03:19–03:31.8](clips/14_board_return.mp4)。**验收**：玩家不看教程也能区分可放与不可放；仍以本项目部署规则判定，所有热区留在安全区内。
- [ ] **I04 上阵落地与资源扣除**：成功放置时给角色落地弹性、短冲击与饼干变化反馈，形成一次完整操作结果。参考：[05 购买成功与奖励 00:52–01:06](clips/05_tasks_rewards.mp4)、[09 连续结果反馈 01:54–02:35](clips/09_board_core_loop.mp4)。**验收**：落地位置与实际战斗坐标一致；动画不阻塞下一次出牌；饼干数值与真实状态同步。
- [ ] **B01 合照受击与危险预告**：家具接近时提示守护压力；真正命中时，相框本体闪红/震动、出现伤害数字与可辨的损坏状态，完好度条随后同步变化。参考：[09 连续操作反馈 01:54–02:35](clips/09_board_core_loop.mp4)、[05 进度变化 00:52–01:06](clips/05_tasks_rewards.mp4)。**验收**：玩家明确看到家具攻击的是合照，不是血条；攻击动画、扣数值、受击反馈时间一致。
- [ ] **B02 猫狗与家具反馈层级**：统一己方攻击、敌方受击、失能退场的轻重、闪光、阴影和短粒子，避免多单位战斗时效果遮住敌人或合照。参考：[06 主玩法区的信息密度 01:06–01:34](clips/06_board_core_intro.mp4)、[09 密集连续操作 01:54–02:35](clips/09_board_core_loop.mp4)。**验收**：十只角色同时在场时仍能识别目标、血量与主要动作；不引入棋盘合成特效规则。
