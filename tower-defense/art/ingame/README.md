# 游戏内美术素材规范

状态：分类决定已落地；逐文件盘点、运行路径和生成器已同步迁移。

## 范围与组织

英雄与敌人动作、战场背景、投射物、治疗/命中/死亡/Boss特效、动作图集及必要的角色参考。战斗图集game.png还带共用UI图标，不可因类别交叉重复存储或删除输入。

运行图拟分package/res/Image/ingame/characters、backgrounds、effects；源图按tools/src角色/特效分类保留，animation-specs仍作为动作单一规格数据源。情绪版、三视图与正式动作来源不能当无用截图删掉。

## 制作与验收

- 接入或替换动作必须遵循[角色动作素材规范](../../../docs/角色动作素材接入与尺寸验收规范.md)，待机主体统一比例、脚底对齐，不逐帧裁边后填满格。
- 中文角色源目录可保留来源含义；运行路径采用小写英文与连字符、无空格、文件名不超过60字符。重命名与数据/生成器更新同时交付。
- 动作JSON、图集格位、锚点、动画命中时刻与PNG相互对应；源GIF不进入游戏加载链，特效运行时使用PNG帧表。
- 阴影、外发光、透明安全边距和加法混合需实际播放检查；不能仅以尺寸脚本通过宣称无裁切或角色等大。
- 单纹理不超过2048。分类整理不改变素材尺寸、色调、动画节奏和战斗数值。
- sprites-legacy.png虽旧仍被gen-shiba-atlas.py读取，保留；同样先核对hero-levels原图/角色三视图等生成链再决定归属。

[逐文件清单](INVENTORY.md)记录每项当前位置、像素、哈希及引用线索；分类结果不能替代动画播放、H5战斗与快手真机验证。
