# 游戏外美术素材规范

状态：分类决定已落地；逐文件盘点、运行路径和生成器已同步迁移。

## 范围与组织

首页背景、关卡封面、头像、收藏册背景与角色展示图、三级形态展示、合照、平台图标/分享/加载素材。角色战斗动作归游戏内，UI组件和字体归UI。

运行图拟分package/res/Image/outgame/home、level-covers、avatars、collection、hero-forms；源图在tools/src按相同用途组织，保留用户附件来源。平台上传图继续放package/yoola-assets，不修改平台目录职责。运行图和用户原图分开，不把预览拼图当正式资源。

## 制作与验收

- 封面按关卡ID对应，保留原图、来源哈希与取景参数；高质量JPG适用于不透明背景，不烧录运行时圆角或关卡文字。
- 头像保留索引与旧ID，保证存档兼容；九宫格裁切需统一圆角与内容区域，检查主体头部及透明边缘。
- 收藏图与战斗动作分离；正面派生图记录取图范围、主体高度和脚底标定，角色不拉伸。人物遮罩/剪影与文本/锁定状态分别处理。
- 关卡数字/名称与收藏说明使用UI字体和布局，不烘进封面。首页必须资源留在主包，不能因分类移动到未经配置的分包。
- 平台图标、加载图、分享图分别按devkit规则验收；网页正常不代表快手上传或真机通过。

十关封面和五张收藏场景采用动态模板路径，未找到完整文件名不能判为无用。生成器、sources.json、裁切记录和已批准原图必须一起保留。[逐文件清单](INVENTORY.md)。
