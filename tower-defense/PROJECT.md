## 项目特有约定

### 渲染
- 只使用 WebGL 1.0：`gameplay/render/gl.js` 是唯一的批渲染器（单 shader、顶点色、mode 0=圆角矩形/圆、1=纹理、2=圆环）
- 禁止 canvas 2D：中文全部走离屏烘焙的字形图集（`res/Image/font-48|28|18.png` + `gameplay/data/font-atlas.js`）
- `gameplay/layout.js` 通过 `KwaiBase.getSystemInfo()` 读取完整安全边界，统一计算可交互内容的 `contentTop/contentBottom`；顶部无控件矩形时保守预留 32px 间距和 64px 平台控制带。背景、战场视觉底层、托盘底色等非交互美术铺满整个画布；按钮、卡牌、部署范围及其触摸命中区须位于安全区内。预览调试层仅标边界，不遮盖美术。
- HUD、暂停按钮、战场、卡牌和菜单按钮必须从同一布局结果派生，绘制与命中不得各自维护坐标
- `Layout.ui.interactiveRect` 是触摸交互的总边界；`Input` 在按钮、卡牌和拖放处理前校验该边界，卡牌还需落在 `ui.cards` 内。战斗部署同时校验交互边界和战场范围。全屏视觉层不参与命中判断。
- H5 Demo 通过 `gameplay/render/safe-area-debug.js` 默认展示 A–E 五区和 iOS 44/68 参考边界；快手容器默认关闭该调试层并读取真机数据
- 纹理对象不带宽高，`draw.texture(tex, texW, texH, sx, sy, sw, sh, ...)` 必须显式传纹理尺寸
- 纹理上传后必须调用 `A.Render.invalidateTexture()`，否则批渲染器的绑定缓存会失效
- `kwaiStandard/main.js` 的 `draw()`（脚手架唯一允许替换的占位绘制）已改为调用 `AIGCUtils.GameLoop.frame()`
- 临时光效试验场已于 2026-11-16 按用户决定移除，不允许通过查询参数进入调试场，也不保留调参脚本于主包。正式战斗特效的默认视觉参数保留在 `scene.js`；任何后续调试工具必须在独立开发分支中实现，确认前不能接入小游戏入口。

- 角色参考按角色目录收纳在 `tools/src/characters/角色/<角色名>/`，跨角色风格参考放在 `tools/src/characters/情绪版/`。其中 `情绪版/三视图.png` 是用户于 2026-11-12 确认的通用三视图母版（60°斜俯、正北 / 正东 / 正南）；柴不破的确认三视图为 `角色/柴不破/柴不破三视图-60度-已确认-v1.png`，战场动作源为同目录 `柴不破背面动作-v1.png`（3×1）。所有角色共用的死亡烟雾位于 `tools/src/effects/defeat-smoke/vanish-smoke-0*.png`；旧图标源放 `tools/src/sprites-legacy.png`
- 角色 / 怪物 AI 生图的强制参考链：每次都输入 `tools/src/characters/情绪版/` 的风格图；所有新三视图任务必须输入通用母版 `情绪版/三视图.png`。角色已有用户确认的专属 `*三视图参考*.png` 时，还必须一并输入，专属结构优先；动作任务使用情绪版、通用母版及适用的专属三视图。缺任一必要参考时暂停正式生成，不得仅靠文字或旧动作表补图。
- 角色 / 怪物 / 特效的新制或重制统一使用“相机位于战场正南、朝正北、俯角 60°”的固定镜头。正式生图和接入前，必须在 `tools/camera-perspective.html` 的 60° 场域预演高度、遮挡、轨迹和贴地透视；已验收素材不自动返工。
- 柴不破、床头柜普通怪与沙发精英的用户确认三视图同为 60°正南→正北结构母版；其动作必须沿用相同镜头、比例和底部锚点。沙发精英扶手从前方连续延伸至侧边和后框，且不使用金属、补丁、紫色光环或常驻发光。
- 例外：通用倒地烟雾采用用户确认的 60°正南→正北低矮斜俯视。源图仅为 `tools/src/effects/defeat-smoke/vanish-smoke-01.png` 与 `vanish-smoke-02.png`，以 0.25 秒依次播放完整圆润棉花烟团、两颗贴地残团与两颗上飘残烟。两帧均为饱满圆润棉花团，不得使用水平裁平或横向拉扁的轮廓。前帧绘制为 55%，残烟为 90%。两帧用共享透明画布整体落入图集，在运行时以固定帧缩放并以脚底基线锚定，禁止逐帧裁切放大；仅玩家英雄死亡触发，任何敌方怪物死亡均直接退场。保留暖白 / 桃粉 / 淡紫的细微绒感，禁止厚雾幕、光环和脏噪点。
- **改动作帧/特效后必须重新执行 `gen-shiba-atlas.py`**；生成器只保留运行时有引用的图集帧
- 界面图标（关闭、返回、箭头、勾选、分享、链接）只在 `sprites.png`；`Assets.sprite()` 先查战斗图集，未命中再回退界面图集
- 字形图集只有 18 / 28 / 48 三档，界面文字不要写 20 / 24 / 26 等其他字号，否则该行会整段不绘制

### 动画与特效
- 角色新增、动作选择、图集接入与验收以 [角色行动动画制作规范](../docs/角色行动动画制作规范.md) 为准；用户仅提供角色图与特点时，按该规范的决策矩阵自动制定行动方案。
- 四个宠物英雄统一采用逻辑直径 40.8–45.6、贴图绘制参考尺寸 55.2–60（414 宽基准）：柴不破 45.6 / 60、锤锤喵 43.2 / 57.6、镭射喵和哈利边牧各 40.8 / 55.2。武器、尾巴和特效不扩大占地；部署中心距取双方逻辑半径之和与 32 的较大值。扩大逻辑占地时，宠物攻击、嘲讽、追击及范围伤害距离、生命与攻击力同步 ×1.2；攻速和怪物参数未改。当前 `radius` 尚未拆分为 `footprintRadius` / `hitRadius` / `renderScale`，后续拆分必须单列为数值回归任务。
- 战场角色统一按实际脚下落点由北向南排序绘制，南侧角色遮住北侧角色；不得再按宠物 / 怪物分组决定层级。现有 `radius` 同时作为脚底圆形体积：存活角色之间保持半径和加 2 逻辑像素的间距。固定部署宠物不被推走，怪物和主动出击的锤锤喵负责避让；怪物与固定宠物相撞时优先在北侧排队。部署时若目标点与存活宠物或怪物的脚底体积相交，则不生成单位也不扣金币。
- 敌人体型按小怪、普通、精英、首领 / 巨型家具怪分档，可比英雄更小或更大；脚底占地决定逻辑尺寸，立体高度、装饰与攻击外框只影响绘制。跨通路的巨型怪需单独实现阻挡与受击规则，不能复用普通怪圆形半径。
- 单位分件动画在 `gameplay/anim/`：`rig.js`（关键帧采样 + 绘制）、`defs.js`（各单位 `states`）
- 角色动作的单一数据源是 `tools/src/animation-specs/<角色id>.json`；`gen-shiba-atlas.py` 生成 `data/character-animations.js`，Rig 读取该数据，禁止重复手填关键战斗时刻。
- 有 `A.Rigs[cardId]` 的单位走分件动画，没有的仍走整图 `Scene.icon`，新增单位可逐个接入
- 攻击伤害**不在起手结算**：`updateUnits` 只切 `anim='atk'` + `pendingHit`，到达 Rig 的 `states.atk.hit` 才 `resolveAttack`；不得再为单位硬编码第二套出手时间
- 射手猫背面动作固定为蓄力 0.10 秒、独立开火帧 0.12–0.18 秒、后坐并在 0.46 秒回到待机；目标左右两侧各用一帧，始终由角色右手持枪；光弹从相应 Rig 的 `muzzle` 锚点生成，命中时才造成伤害
- 射手猫被击败时先向后仰 0.12 秒，切换到用户确认的仰面晕倒帧；姿势保持不透明，在 0.46 秒时生成三帧纯白烟雾并直接移出单位列表。烟雾的扩散由三张素材帧表达，不可再以运行时缩放伪造。死亡持续时间读取 Rig 数据，不能为此单位另写硬编码
- 柴不破不进入攻击流程；嘲讽仍由战斗逻辑处理，但不播放光盾特效。战场固定使用 60°背面完整姿势；待机时大盾从观察者左侧露出，受击在 0.34 秒内轻微后移、失衡后回正，保持角色体积而不压扁；死亡切换为仰面晕倒（头朝战场南侧），姿势不渐隐，随后复用通用白烟雾退场。
- 台灯小怪使用 `small` 敌人档（逻辑直径 22）：移动循环为起跳 / 落地，近战攻击在 0.22 秒由灯罩前撞命中；命中使用暖色冲击而非刀光。动作源为 `tools/src/characters/角色/台灯小怪/lamp-minion-actions-v2.png`，3×2 表统一取帧；正 / 侧 / 后三视图参考为同目录 `台灯小怪三视图参考-v2.png`；两者均以情绪版风格图与该三视图为输入。死亡侧翻姿势保持不透明，随后复用通用白烟雾。
- 床头柜怪复用普通怪稳定内部 id `normal` 与既有数值（逻辑直径 30）：固定相机在战场正南、朝正北、俯角 60°。运行时使用待机、缩小跳步、双拳蓄力 / 撞击、仰倒五态；跳步帧按待机 86% 绘制，攻击在 0.30 秒撞击帧命中，受击不切姿势也不播放白闪。`normal.json` 是唯一动作规格，保留 `normal` id、波次引用、速度、生命、攻击、间隔、伤害和金币。
- 近战猫复用移动近战位的内部 id `war` 与既有数值（逻辑直径 30）：正面 / 背面均有待机、走步、蓄力、挥锤、受击与倒地帧。移动和目标在角色上方时使用背面 Rig，目标在角色下方时使用正面 Rig；任一瞬态动作结束后固定回背面待机。动作源为 `tools/src/characters/角色/近战猫/近战猫动作-v2.png`，4×3 表统一取帧，三视图为 `近战猫三视图参考-v1.png`；正面命中帧使用闭眼表情。攻击命中维持 0.20 秒，挥锤刀光仍由运行时绘制，死亡后复用通用白烟雾。
- 哈利边牧复用法师位内部 id `mage` 与既有数值（逻辑直径 28）：战场固定背面，动作源为 `tools/src/characters/角色/法师狗/mage-dog-back-actions-v1.png`（3×2），包含待机、蓄能、释放、收势、受击与仰面晕倒。攻击在 0.28 秒的释放帧命中；用户提供的骨饼干能量 GIF 收纳为 `tools/src/effects/mage-biscuit-flight/mage-biscuit-flight-v1.gif`，生成阶段拆为 `res/Image/mage-biscuit-flight.png`（4×3、12 帧、单格 128px、80ms / 帧）。运行时根据投射物累计时间循环取格，所有帧共享中心锚点，并按飞行方向旋转；GIF 本体不进入主包。用户提供的四阶段砸地序列收纳为 `tools/src/effects/mage-biscuit-impact/mage-biscuit-impact-v2.png`，生成 `res/Image/mage-biscuit-impact.png`（4×1、单格 160px）。其源图为横向拼接稿，生成时对内容区左侧做 26px、右侧做 14px 渐隐，并置入 16px 透明安全区，避免烟尘/外发光在帧边界被硬切或采样串色；固定锚点 `[80,108]` 与绘制尺寸换算后，视觉尺寸和命中落点保持不变。起爆、爆发、烟尘、残光依次持续 0.08 / 0.20 / 0.16 / 0.16 秒，总计 0.60 秒；残烟从出现起线性淡出，恰在生命周期终点归零。法师特效共用 `scale` 为 `0.6`（飞弹 45.6；落地画布 90、有效画面约 54×72 逻辑像素），不影响角色或数值。命中不叠加通用范围圆环，死亡仍接通用白烟雾。
- 奶糖喵复用治疗位内部 id `healer` 与既有数值（逻辑直径 20.4）：战场固定背面，三视图源为 `tools/src/characters/角色/奶糖喵/奶糖喵三视图.png`，动作源为同目录 `奶糖喵动作.png`（3×1），依次为待机、治疗与受击。每两秒周期起手进入动作，在 0.30 秒中间治疗帧确认目标并结算数值；特效从法杖绿球锚点以淡绿 / 粉色短粒子飞至目标脚边，随后绽开低矮柔光与上浮小十字。未提供独立倒地帧前，倒地状态复用待机姿势与时间线。
- 战场中的英雄与敌人保留一层复用 `fx-glow` 柔边纹理的近黑色椭圆脚下阴影：面积系数为 0.70，英雄最大不透明度为 0.40，怪物按原比例提升至 0.48。英雄阴影按动作贴图的实际脚底定位，避免被高大的角色贴图遮住；不绘制常驻色块 / 光环、减速环、首领环或战士驻点环。血条与攻击、命中、死亡等短暂特效仍保留。
- `hitstop` 只压缩战斗推进（`battleDt`），特效仍按真实 `dt` 衰减，否则闪点会一起卡住
- 死亡单位要等 `die` 动画播完（`dieT`）才移出 `S.units`，**名额统计必须跳过 `dead`**，否则尸体卡上限
- 加法混合通过 `A.Render.setAdditive(true/false)` 切换，进出都会 flush；着色器带 `uAdd`，
  在加法模式下把贴图 alpha 预乘进 RGB，否则 PNG 透明区的白色会把四边形加成方块
- 旋转与翻转在 `gl.push` 的 CPU 端处理（`opts.rot` / `opts.flipX`），不改 shader、不扩顶点格式
