# 局内视觉基准 v1（此前概念草案，未获确认）

此草案早于参考视频逐帧取样，不能作为定稿或接入依据。后续审查以[视觉规范 v0.1](视觉规范-v0.1.md)为准。逐帧证据及生产方式见[视觉风格取样与生产方式](../../../reference-analysis/IMG_4018/视觉风格取样与生产方式.md)。本基准用于《猫狗大战家具》自己的界面。参考录屏只用于观察材质、文字层级、颜色和交互节奏；[同屏样张 v2](visual-system-v2.png)是概念图，不是可直接切用的游戏资源，样张文字仍须以运行时文案为准。

## V01 风格

- 首页与局内使用同一组暖木棕、奶油白、琥珀金、柔和草绿；猫狗和家具的形体保持圆润、清晰的深浅边界。
- 面板有轻微厚度、顶部高光和短接触阴影。阴影随按钮、卡牌和角色本体运动，不缩放背景。
- 合照相框是守护目标，家具攻击和受击反馈锚定本体；战场透视沿既定正南朝正北的美术规则，不由样张改玩法坐标。

## V02 文字与信息层级

| 层级 | 用途 | 处理 |
|---|---|---|
| 一级 | 开始、胜负、关卡标题 | 最大字号，暖棕粗轮廓、浅色字面，远看先认出动作 |
| 二级 | 波次、剩余敌人、金币、卡费 | 明显大于说明字，数字与中文对齐同一基线 |
| 三级 | 按钮、角色名、状态原因 | 简短完整词，不用「波／金／席」单字缩写 |
| 四级 | 操作提示与说明 | 高对比、低装饰；过长时改写文案而不是压缩到难读 |

当前运行时中文字使用 `ZCOOLKuaiLe-Regular.ttf`、拉丁数字使用 Fredoka 600，经离线字形图集进入 WebGL 1.0。具体参考游戏字体未识别，后续按真机可读性调整字形与描边；样张不能替代字形图集验收。

顶部 HUD **只放「第 x/10 波」「剩余敌人 x」与暂停**；窄屏可改为「第x/10波」「剩余x」，不用单字。金币位于商店资源条，卡费位于卡牌。合照完好度只在相框旁的状态反馈中呈现。上场人数不常驻展示；席位上限和扩建规则继续生效，已满时在操作处给出提示。

## V03 颜色与状态

| 语义 | 主色方向 | 同步线索 |
|---|---|---|
| 主界面与面板 | 奶油白、暖棕 | 边缘厚度、阴影、标题位置 |
| 金币与费用 | 琥珀金 | 钱币图标、数字变化 |
| 可执行与成功 | 草绿 | 勾、弹起或短闪 |
| 危险与受击 | 暖红 | 相框震动、受击数字、短促闪烁 |
| 不可执行 | 降低饱和度 | 明确的「金币不足」「席位已满」文字，不能只变灰 |

本轮只将 HUD 的显示范围对齐上述约定，未改变战斗生命、席位、金币、波次、拖卡与暂停机制。V01–V03 待样张审查及真机可读性验收后，再批量应用到按钮和战斗反馈。
