# 局内商店卡片排版 v1

状态：`codex/shop-card-layout` 分支实现，静态检查通过，视觉与真机待用户验收。卡片排版不改价格、合成或上阵；锁定规则随后按用户决定调整为所有星级可锁，见 `shop-lock-rules-v1.md`。

| 内容 | 处理方式 | 原因 |
| --- | --- | --- |
| 卡片底板、描边、内高光、头像槽 | WebGL 圆角几何 | 跟随槽位尺寸绘制，避免横向拉伸和底图边缘溢出 |
| 费用圆章、星级章、详情提示、锁定按钮 | WebGL 几何及位图字体 | 状态、位置与尺寸由布局数据控制 |
| 名称、职业与关键数值、费用、锁定文案 | 位图字体实时绘制 | 依卡片可用宽度等比缩放，禁止越出内边距 |
| 角色正面立绘 | 保留透明 PNG | 角色形象和细节不能由几何图形替代 |
| 商店木质托盘、刷新及扩建按钮 | 暂用现有素材 | 本轮聚焦角色卡片，避免扩大视觉变动范围 |

卡片采用左侧头像、中央上下两行信息、右上费用、右下锁定按钮的布局。名称宽度止于费用章左边；属性宽度止于锁定按钮左边。一至三星都有锁定按钮，二星及三星的星级章放在头像槽下方；锁定的可点区域比可见按钮大，仍限制在卡片内。头像详情的命中区域与可见头像槽共用 `Layout.shopCardParts`，锁定命中区由 `Layout.shopLockRect` 提供。

旧整图 `shop-card.png` 移到 `design/legacy-package-assets/` 留存，运行时不再加载。视觉字号、文字清晰度和触摸手感由用户在本地预览及真机确认。

## 卡池内拖动预览

原拖动预览是固定 104×68 的临时小卡，名称与价格按 18px 原尺寸叠加，文字会越过右边框。现改为浮起的同款商店卡片：宽高与原槽位一致，复用头像、名称、属性、星级和实际售价排版。按下时记录触点在原卡片中的位置，拖动时该位置对齐当前触点；仅在预览触及安全区边缘时夹紧。底边保留 5px 阴影，源槽位在拖动时降至 45% 不透明度。拖入战场后的落点预览保持独立，不改购买、合成和部署判定。视觉待用户验收。

## 战场落点预览

镭射喵在战场拖动时不再显示旧十字弓职业图标和大号落点圆圈，改绘制与正式单位一致的背面待机姿势、柔边脚下阴影和细短有效/无效位置条。其他角色也优先复用各自战场姿势，缺少姿势时使用当前角色立绘。攻击范围轮廓仍显示供布阵判断；购买与部署判定未改变。视觉待用户验收。
