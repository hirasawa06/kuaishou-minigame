# 双开门冰箱怪动作源图 v1

## 现状

- 本目录保存 2026-11-17 生成的首领动作源图；尚未登记到动画规格、图集或运行时。
- 固定镜头：相机位于战场正南、朝正北、俯角 60°。
- 所有动作图为透明 PNG；它们保留完整角色外框，不应按可见边缘逐帧裁切并填满图集格。

## 决定

- 基准图：`双开门冰箱怪三视图-60度-v1.png`。
- 动作表：待机 1 帧、移动 2 帧、单体攻击 3 帧、相框攻击 3 帧、受击 1 帧、倒地 2 帧，共 12 帧。
- 单体攻击与相框攻击均采用“蓄力 → 命中 → 收势”；命中分别建议取第 2 帧和第 3 帧。
- 冷气冲击圈、跳冰块、震屏、击中粒子与死亡烟雾不烘焙在角色帧中，接入时作为独立特效处理。

## 提案

- 接入前以待机的机身宽度、躯干高度和双脚接地中心建立基准卡；再将各帧映射进共享透明画布。
- 首领动作应使用标准状态名 `idle`、`move`、`atk`、`hurt`、`die`；相框攻击可作为具明确玩法含义的独立攻击状态或技能相位。

## 待验证

- 需要人工核对每帧主体比例、脚底基线、透明边缘及慢放连播；当前源图未宣称已满足图集尺寸和 1 逻辑像素落点门槛。
- 接入后需执行图集重建、资源门禁、400 秒仿真、H5 动画定格与快手真机验收。
